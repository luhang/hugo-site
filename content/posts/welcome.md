## 欢迎

这是一个使用 Hugo 构建的静态文档站点。所有内容都用 Markdown 编写。

### 特性

- **快速构建**：Hugo 是最快的静态站点生成器之一
- **Markdown 支持**：直接用 `.md` 文件编写内容
- **灵活组织**：支持目录、标签、分类
- **GitHub 同步**：内容可以存放在 GitHub 仓库中

### 快速开始

1. 在 `content/posts/` 目录下创建新的 `.md` 文件
2. 添加 front matter（标题、日期等）
3. 编写 Markdown 内容
4. 运行 `hugo server` 预览

```bash
hugo server --buildDrafts
```

访问 `http://localhost:1313/` 查看效果。
